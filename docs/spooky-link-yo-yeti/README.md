# Prototype v3 — Cash Collect (inspired by Spooky Link: Yo Yeti)

Working notes for a second prototype built around a different slot mechanic.
The current game (Proto v2, Hold & Spin) is **not** changed by any of this.
No code, math or art exists yet for v3. These files only record what we have
researched and agreed so far.

## Files

| File | What it holds |
|---|---|
| `RESEARCH.md` | What public sources say about Spooky Link: Yo Yeti, Mo Mummy and Mo Mo Mo Mummy. Each claim has a source and a confidence level. |
| `GAME_LOGIC_DRAFT.md` | Our proposed rules for the v3 Cash Collect bonus, with open questions for the designer. |
| `SESSION_LOG.md` | What was asked and decided in each working session. |

## Ground rules (from the designer)

- The bonus is a **Cash Collect** feature based on **Mo Mummy**, with **three
  pot modifiers** added on top, as in Spooky Link: Yo Yeti.
- Art and math instructions come later. For now we define game logic only.
- Our version is original: we copy the mechanic's structure, not Aristocrat's
  names, characters, art, sounds or exact values. Final names and theme are
  still open (see the open questions in `GAME_LOGIC_DRAFT.md`).
- When v3 is built, it follows the v2 conventions: math in a workbook under
  `math/`, rules in a `RULES.md`, award logic in the engine only.
